# Era Explorer — ATP 2000–2026

Every ATP tour player of the last 26 years on one rating scale, built from
10.6M service points. Compare careers, weigh eras against each other, play
out matches that never happened, and run the All-Time Slam.

A single self-contained HTML file — no backend, no tracking, no cookies.
Built from a private tennis data warehouse (Match Charting Project,
community mirrors of tour results, tennis-data.co.uk).
